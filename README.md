***Exercício 1: Validador de Senhas Fortes***
Passo a Passo Lógico para a Resolução:
Entrada de dados: O programa começa pedindo para o usuário digitar uma senha.

Verificar comprimento: A primeira coisa que o programa faz é checar se a senha tem pelo menos 8 caracteres. Se não tiver, ele já diz que a senha é fraca.

Verificar letra maiúscula: Em seguida, o programa verifica se tem pelo menos uma letra maiúscula. Se não tiver, a senha também é considerada fraca.

Verificar número: O programa também checa se tem pelo menos um número na senha. Caso não tenha, a senha é considerada fraca.

Verificar caractere especial: O último critério é verificar se tem pelo menos um caractere especial (como !, @, #, etc). Se faltar esse critério, a senha é considerada fraca.

Resultado: Se a senha passar em todas as verificações, o programa diz que a senha é forte. Caso contrário, ele avisa que a senha é fraca.


***Exercício 6: Cadastro Simples de Produtos***
Passo a Passo Lógico para a Resolução:
Criar a classe Produto: Primeiro, criamos uma classe chamada Produto. Essa classe tem três propriedades: nome, preço e quantidade. Essas propriedades vão guardar as informações de cada produto.

Entrada de dados: O programa pede para o usuário digitar o nome, preço e quantidade de 3 produtos. Isso é feito em um loop, repetindo 3 vezes para cadastrar os 3 produtos.

Armazenar os produtos: Cada produto é armazenado em um array, que é uma lista de objetos do tipo Produto. Assim, conseguimos guardar todas as informações de cada produto no mesmo lugar.

Calcular valor total: Depois de cadastrar todos os produtos, o programa calcula o valor total em estoque, multiplicando o preço de cada produto pela quantidade e somando tudo.

Exibir dados: Finalmente, o programa mostra na tela todos os produtos cadastrados e o valor total do estoque.
